Abre C:\ocilab\terraform\main.tf e adiciona este bloco NO FINAL

  source = "./datascience"

  compartment_id = oci_identity_compartment.aiops_lab.id
  subnet_id      = module.network.public_subnet_id
}

Abre C:\ocilab\terraform\outputs.tf e adiciona no final:

output "notebook_session_url" {
  value       = module.datascience.notebook_session_url
  description = "Abre este link para acederes ao Jupyter Notebook"
}
